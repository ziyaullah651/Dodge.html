Inclusive Accessibility Toolkit

Practical steps & animated explainers to make college accessible for differently-abled students

How might we ensure inclusive accessibility?

This mini project demonstrates ideas, policies and quick wins — each illustrated with a short looping animated explainer (SVG animations acting like short videos).

1. Physical Access & Universal Design

Ensure ramps, elevators, wide doorways, tactile surfaces and clear signage.

2. Digital Accessibility

Provide captions, transcripts, WCAG-compliant websites and accessible LMS content.

3. Inclusive Policies & Support

Train staff, create an accommodations office and run awareness programmes.

How to use / publish

  1. Extract the project folder and open index.html in a browser (Chrome, Firefox).
  2. To publish on GitHub: create a repo and push these files; enable GitHub Pages from main branch (or use docs/ folder).
  3. All animated explainers are inline SVGs (scalable, accessible, small). Use the Play/Pause buttons to control them.

Suggested next steps

  • Add real captioned MP4 explainers (replace SVG with <video> tag files in /assets).
  • Localize text and create alternative-language captions and transcripts.
  • Run accessibility audits (axe, Lighthouse) and iterate.
