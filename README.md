# Inclusive Accessibility Toolkit (College)
A lightweight static site demonstrating ideas to ensure inclusive accessibility for differently-abled students in college.
Each idea is paired with a short looping inline SVG "animated explainer" (acts like short videos).

## Features
- Three illustrated explainers (physical access, digital access, policy & support).
- Play/Pause controls (keyboard-accessible).
- WCAG-friendly structure: semantic HTML, aria-labels, focusable elements.

## How to deploy
1. Extract the folder and open `index.html` locally to preview.
2. To publish on GitHub Pages:
   - Create a new repository.
   - Push all files to the `main` branch.
   - In repo settings -> Pages -> set source to `main` branch and `/ (root)`.
   - Visit `https://<your-username>.github.io/<repo-name>/`.

## Extend
- Replace inline SVGs with captioned MP4 videos in `/assets`.
- Add transcripts and translations in separate files.
- Run Lighthouse and axe accessibility audits and iterate.
